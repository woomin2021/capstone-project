# JJB (집 잠시 빌려드립니다)

대학생·취업준비생·직장인이 학교·직장 인근의 남는 방을  
**짧은 기간, 안전하게, 합리적인 가격으로 대여**할 수 있는  
**중·단기 임시 주거 플랫폼**입니다. 

---

## 📌 프로젝트 개요

- 프로젝트명: JJB (집 잠시 빌려드립니다)
- 프로젝트 유형: 캡스톤 디자인 (팀 프로젝트)
- 목적  
  - 기숙사 수용 한계, 높은 주거비, 단기 체류 공간 부족 문제 해결  
  - 1~6개월 중·단기 거주 수요를 위한 보증금 없는 임대 플랫폼 제공

---

## 👥 팀 구성 및 역할

- **woomin (본인)**  
  - **프론트엔드(Android) 및 백엔드 연동 & 서버 **

---

## 🎯 타겟 사용자

- 대학생 / 취업 준비생
- 단기 인턴, 지방 출퇴근자
- 단기 출장 직장인
- 공실을 보유한 개인 호스트 (1인 가구)

---

## 💡 기획 배경 및 해결 방안

### 기존 문제점
- 전·월세 중심 부동산 → 단기 거주에 부적합
- 높은 보증금과 중개 수수료
- 숙박 플랫폼은 장기 체류 시 비용 부담 큼

### JJB의 해결 전략
- 1~6개월 중·단기 거주에 특화
- 보증금 없는 박 단위 결제 구조
- 리뷰, 사진 인증, 채팅, 온도(신뢰 지수) 기반 매칭으로 신뢰도 강화 

---

## ⚙️ 주요 기능

- 회원 관리  
  - Firebase Auth + Spring Boot 토큰 검증
- 매물 등록 및 관리  
  - 방 정보, 사진, 편의시설, 사용 가능 기간 및 가격 설정
- 위치 기반 매물 탐색  
  - 대학·직장 인근 기준 추천
- 예약 및 채팅  
  - 입주/퇴실 날짜 선택, 앱 내 실시간 소통
- 리뷰 및 온도 시스템  
  - 별점·리뷰 기반 사용자 신뢰 지표 제공  
---

## 🛠 기술 스택

### Front-end
- Android (Java)
- XML 기반 UI

### Back-end
- Spring Boot (Java)
- REST API

### Database / Infra
- Firebase Authentication
- MySQL
- DBeaver
- Naver Cloud Platform

### Collaboration
- Git / GitHub

---

## 🧩 시스템 구조 (요약)

- 사용자 구분: 게스트 / 호스트
- 기능 흐름  
  회원가입 → 로그인 → 매물 탐색 → 예약 → 채팅 → 리뷰 작성  
  호스트: 집 등록 → 예약 관리 → 리뷰 확인 

---

## 📈 기대 효과

- 사용자: 초기 주거비 부담 완화, 이동 시간·교통비 절감
- 호스트: 공실 활용을 통한 부가 수익 창출
- 지역사회: 공실 문제 완화 및 지역 경제 활성화
